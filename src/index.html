Note's

Administrator Privileges: For optimal functionality, run the program with administrator privileges. This ensures seamless access to system settings for DNS configuration.

Patience is Key: Setting up DNS servers may take some time, especially for certain configurations. Please be patient and wait until you receive the confirmation message before proceeding.

Network Stability: Ensure stable network connectivity throughout the DNS setup process to avoid interruptions or errors.

Backup DNS Settings: Before making any changes, consider backing up your current DNS settings to revert to in case of any issues.

Security Measures: Exercise caution when changing DNS settings and only use trusted DNS servers to prevent security risks or potential DNS hijacking.

Testing and Troubleshooting: If you encounter any issues during or after DNS setup, utilize built-in testing and troubleshooting tools to diagnose and resolve any connectivity issues.

Regular Maintenance: Periodically review and update DNS settings to ensure optimal performance and security of your network.
